# NEXUS — Capa de nomenclatura RD

Se separa el nombre visible de obra del producto técnico de Biblioteca.

Ejemplo validado:
- Nombre visible: Derretido para juntas
- Recurso canónico: MAT-09-000294
- Producto de Biblioteca: Boquilla cementicia para juntas 1–5 mm
- Unidad: funda

El vínculo, precio y trazabilidad siguen usando el recurso canónico. La interfaz y el APU usan la nomenclatura local definida por la regla de conocimiento.
