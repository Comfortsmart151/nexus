# NEXUS V5.0.1 — UX, trazabilidad y revisiones

Base: V5.0 Professionalization Core.

## Implementado
- Sistema global de notificaciones tipo toast, reutilizable en toda la aplicación.
- Configuración y revisiones ya emiten feedback profesional.
- Revisiones de presupuesto ahora congelan snapshot de partidas, cantidades, PU e importes.
- Comparador Rev. N vs Rev. N-1: agregadas, eliminadas, modificadas y variación RD$.
- Numeración documental automática configurable: prefijo + año + proyecto + revisión.
- Configuración incorpora prefijo documental.
- Duplicación de proyecto con selector: estructura, APU y configuración económica.
- Trazabilidad visible para partidas originadas desde Planos: origen, desperdicio y ajuste de PU.
- Se conserva trazabilidad de recursos (fuente, fecha, confianza y estado de precio) existente en V5.0.
- Se restituyó/aseguró el modal de edición de datos generales del proyecto.
- Estados vacíos y confirmaciones existentes se mantienen bajo el lenguaje visual V5.

## Compatibilidad
Las revisiones creadas antes de V5.0.1 siguen siendo visibles. Al no contener snapshot detallado se muestran como revisiones legadas y no inventan diferencias de partidas.
